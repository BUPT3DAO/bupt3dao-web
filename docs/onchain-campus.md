# 链上邮园：玩法与发布手册

## 体验范围

链上邮园是使用 **Base Sepolia 测试网** 的教学游戏。官网 `/game` 介绍玩法，`/game/learn` 解释交易和资源规则，`/game/campus` 仅向登录且未封禁的成员加载游戏配置和个人界面。需要电脑浏览器钱包与少量免费的测试网 ETH 付 gas；本站不会索取私钥或助记词。

合约是公开的链上程序：即使官网页面要求登录，任何人仍可从区块浏览器读取数据或直接调用合约。游戏不提供真实货币、可出售资源或站内付费。测试网将来可能重置；一期不承诺测试网进度永久存在。

## 玩法与合约规则

- 每个钱包只能 `join()` 一次，获得一张不可转让的 ERC-721 / ERC-5192 通行证和知识、算力各 60 点。通行证编号由钱包地址确定。
- 沙河图书馆生产知识，西土城主楼生产算力；初始等级都是 1，每级每小时增加 10 点相应资源。收益按秒累计，最多计入最近 24 小时离线时段；页面预览余额无需交易，`collect()` 会正式结算。
- `upgrade(0)` 升主楼，`upgrade(1)` 升图书馆。两种资源各花费 `50 × 当前等级²` 点；建筑上限 5 级。升级会先按旧等级结算。
- `contribute(amount)` 为公共「点亮邮园」项目各投入 `amount` 点知识和算力。第 N 轮目标为 `1000 × N`；达到目标时开始下一轮。一次交易只能投入本轮剩余目标，不跨轮。
- 成就记录在玩家状态的位标记里，包含加入、第一次升级、第一次贡献、双建筑满级及累计贡献门槛。通行证元数据和 SVG 图片由合约直接生成，不依赖站外图片服务。
- 部署钱包成为不可更换的 guardian，仅能调用 `setPaused(bool)` 暂停或恢复写入；不能转走通行证、修改玩家资源或提取资金。合约无代理和升级入口，因此发布后业务规则不可更改。请用由社区保管的专用钱包部署，不要用个人主钱包或提交私钥到代码仓库。

## 本地验证

需要 Node 22、pnpm 10.29.2、Foundry。先在仓库根安装依赖，再到 `contracts/` 执行：

```bash
pnpm install --frozen-lockfile
cd contracts
forge fmt --check
forge test
forge build
```

CI 会执行同样的格式、测试和构建检查。`forge test` 含时间推进、收益封顶、连续结算、资源不足、跨轮、暂停和不可转让测试。前后端检查仍按 [开发文档](development.md) 执行。

可选的本地整链联调：启动 `anvil`，用测试账号在本地部署合约；把 API 的 `GAME_CHAIN_ID=31337`、`GAME_RPC_URL=http://127.0.0.1:8545`、`GAME_CONTRACT_ADDRESS=<本地地址>`、`GAME_ENABLED=true` 写入本地 `.env`，再启动 API 和 Web。仅本地开发允许 31337；生产配置校验强制 84532。不要把 Anvil 的公开测试私钥用于任何真实网络。

## Base Sepolia 部署与开放门槛

1. 在评审完成后，由社区确定专用部署钱包和保管人。钱包内只需少量 Base Sepolia 测试 ETH。**不要把助记词、私钥、keystore 密码、RPC 凭据或签名材料发到 PR、聊天或网站**。
2. 在干净的提交上复跑 `forge test` 和 `forge build`。使用本地加密 keystore 或硬件钱包执行部署，例如在 `contracts/` 下运行 `forge create src/PostCampus.sol:PostCampus --rpc-url https://sepolia.base.org --account <本地账户名> --broadcast`。检查返回的部署交易、链 ID `84532` 和合约地址。
3. 在 BaseScan 上验证合约源码和编译设置（Solidity 0.8.28、优化器 200 次）；检查合约字节码对应本次构建，并确认 `guardian()` 是预期的社区钱包。至少用两只不同的钱包实测领取、结算、升级、共建、不可转让、暂停与恢复。
4. 确认公开 RPC 的浏览器访问与限流可接受；生产若用自有 RPC，必须是允许浏览器直连的 HTTPS 地址，不能把私密 API key 当作保密信息放在这里。记录合约地址、部署交易和验证链接供社区审阅。
5. 仅完成上述检查后，才在服务器 `docker/.env` 对应实际部署配置里写 `GAME_CHAIN_ID=84532`、`GAME_CONTRACT_ADDRESS=0x...`、`GAME_RPC_URL=https://...`、`GAME_ENABLED=true`，按现有发布流程重建 API 容器。打开 `/api/game/status`、登录后的 `/api/game/config` 和 `/game/campus` 检查。配置关闭时导航入口隐藏；即使代码已合并，也不会自动上线游戏。

本 PR **不部署合约、不启用生产开关、不合并 main**。测试网部署涉及社区钱包授权和测试币，必须由保管人单独确认。

## 停用与故障

- 网站紧急下线：先将服务器 `GAME_ENABLED=false` 并重新创建 API 容器；导航入口与合约地址配置立即关闭。已上链进度不会删除。
- 合约异常：guardian 在钱包中调用 `setPaused(true)`，停止新的领取、结算、升级、贡献交易。链上读取与数据仍保留。合约无法升级；若需要改规则，部署新合约并由社区公告迁移策略。
- RPC 不可用：页面显示读取失败和重试，不应显示旧钱包的校园数据。交易哈希存于当前浏览器本地、按钱包地址和合约地址隔离；页面重开后会继续查询确认。可以用区块浏览器独立确认交易状态。
- 钱包切换或退出：前端卸载旧玩家视图，重新登录后只读取新钱包的链上状态。钱包签名只用于身份验证和交易，官网不保存玩家私钥。
